# 每日任務

每天固定時段任務提醒與打卡，加上一隻靠完成任務養大的三頭龍。純前端網頁App，資料存在瀏覽器的 localStorage，不需要任何後端伺服器。

## 使用方式

直接用瀏覽器打開這個網站即可使用；用 Chrome/Edge 開啟時可以點網址列的「安裝」圖示，把它安裝成獨立的桌面/手機App。

## 功能

- **今日總覽**：時間軸列出今天所有固定任務，可打卡完成，過期未做會標紅
- **任務管理**：新增/編輯/刪除任務，設定提醒時間（或不指定時間）與重複星期
- **寵物**（主頁）：一隻一出生就破殼的三頭龍（`pet.js`／`pet.css`）。疲勞、飢餓、口渴、大小號、髒污度與五大營養依真實時間變化，關掉 App 也照算；完成任務賺金幣（每個 +10，全部完成再 +30），在商店用金幣買食物、水、補給和稀有道具；寵物不會跳通知。場景是像素風（`<canvas>` 低解析度放大，預設黑白 1-bit 網點，可切回彩色），點地面龍會走過去，點床睡覺、點馬桶上廁所、點湖泡澡（洗掉髒污度）、點便便清掉；背包在場景右側，把食物或水拖到地上，牠會自己走過去慢慢吃（食物約 4 秒、水約 3 秒，地上的東西會一口一口變少）。大約每 3–4 小時要照顧一次，照顧得好會一點一點長大（滿級約 100 天），沒顧好會生病、停止成長。`artifact.html` 把這兩個檔案內嵌在 `PET-CSS`／`PET-JS` 標記之間，改完要同步

## 技術

純 HTML/CSS/JavaScript，無框架、無建置流程、無後端。資料透過瀏覽器 `localStorage` 儲存在本機。
